SSPGPT v0.7.1 online-update channel

This channel is for Ghosts that have already installed the v0.7.1 full NAR.
Installed Ghost directory remains v07; the update channel is separated as v071 to prevent a pre-v0.7.1 installation from receiving incompatible YAYA boot paths.

This SSP native update channel intentionally contains YAYA/presentation bootstrap files only.
It does not replace Runtime, Bridge, MemoryService, TouchProgress, Plug EXEs, YAYA DLL, local model assets, config policy, character files, memory, credentials, profile state or logs.
Core architecture upgrades must use a full NAR.
