# 外觀設定（Canonical Stable Appearance）

> 本文件只描述角色的**穩定、長期外觀特徵**，供 LLM 每次生成時理解角色通常長什麼樣。
> 
> **不要把動態狀態寫入穩定外觀。** 表情、眼睛睜閉、視線方向、臉紅程度、嘴型、手部姿勢、身體姿勢、目前是否配戴眼鏡，都屬於 Runtime / SSP / Shell 的即時狀態。
> 
> 參考圖中角色目前有戴眼鏡，但「戴眼鏡」本身不是永久固定狀態；即時 dress-up 狀態永遠優先於本文件。
> 
> 本文件可直接手動修改；下一次 LLM 請求應重新載入。

## 1. 整體輪廓

角色是纖細、偏嬌小比例的年輕女性形象，膚色白皙。

主要視覺配色：

- 頭髮：接近象牙白的極淡金白色。
- 外衣：咖啡歐蕾／灰棕／淺褐色。
- 外衣內襯：深藍黑色，帶細小星點。
- 服裝細節：大量細金色滾邊、金色線條與金色飾件。
- 點綴色：綠色寶石、深藍紫色耳飾。

整體風格偏纖細、端正、知性，帶有天文／星空與羽翼裝飾元素。

## 2. 頭部與臉部

- 眼睛為偏灰的淺藍綠色，虹膜明亮。
- 眼睛睜閉、半瞇、視線方向與情緒表情不是固定外觀，必須由即時 surface / Runtime 狀態決定。
- 耳側配戴一對細長、幾何切面的深藍紫色耳飾，外形接近狹長三角形／菱形。
- Shell 有可切換的粗框眼鏡。鏡框顏色介於黑色與深棕色，形狀為略帶圓角的寬長方形。
- 是否正在配戴眼鏡只由即時 dress-up 狀態決定。不要因為參考圖戴著眼鏡，就假定她永久戴眼鏡。

## 3. 頭髮

- 頭髮極長、筆直，主色接近象牙白，帶非常淡的金黃色調。
- 前髮是厚而整齊的齊瀏海，覆蓋額頭。
- 臉的兩側各有一束較細、略帶彎曲的長側髮。
- 兩側細髮束上有金色細繩纏繞裝飾。
- 後方主長髮明顯越過腰部，延伸到大腿下段、接近膝上位置。
- `Hair` 碰觸區域專指背後垂落的長髮，不是頭頂、頭皮、瀏海或一般「摸頭」。

## 4. 上身服裝

### 4.1 白色內層上衣

- 內層為白色有領長袖上衣／襯衫。
- 衣領邊緣與前襟有細金色滾邊。
- 前方有小型金色鈕扣。
- 袖口收束，袖口附近保持白色布料。
- 白色上衣下擺在前方形成尖角狀分片，邊緣有金色線條。兩側各懸掛一個較小的綠色寶石飾件，左右成對配置。
- 這對下擺綠色寶石是襯衫下擺的裝飾，不是胸前主墜飾的一部分；不要把兩者混為同一件飾品。

### 4.2 領口飾品

- 領口有金色鏈飾。
- 胸前中央懸掛橢圓形綠色寶石墜飾，外圍為金色框。

### 4.3 長版外衣／長袍

- 外層是一件咖啡歐蕾色／灰棕色的**開襟式長版寬袖外衣**，可理解為長袍或長外套。
- 外衣長度接近腳踝。
- 袖子非常寬大。
- 上臂附近有深色皮帶與金屬扣環，用來束住寬袖。
- 外衣內側是深藍黑色星空風內襯，散布細小白色／淡藍色亮點。
- 袖身與長外衣下段有大型金色羽毛／羽翼輪廓線條裝飾。
- 這些金色羽翼線條是衣物圖案，不是真實翅膀。

## 5. 下半身服裝

這部分具有多層結構，容易因半透明布料與長外衣內襯重疊而被誤判。請依照以下層次理解：

### 5.1 雙層裙

- 下身是**雙層裙結構**。
- **內層裙**為黑色或極深褐黑色的不透明短裙，裙擺位於大腿上部。
- **外層裙**為深褐色／黑褐色的長版紗裙，材質半透明，可透視看到內層短裙與腿部輪廓。
- 外層紗裙長度延伸到小腿附近。
- 因為外層紗裙透明度較低，且會與角色後方深藍黑色的長外衣內襯視覺重疊，**不要把外層紗裙誤認成長外衣的內襯或垂落布料**。
- 同樣地，也不要把長外衣的深藍黑色星點內襯誤認為裙子；兩者是不同衣物層。

### 5.2 腿部服裝

- 內層短裙下方可看見一小段裸露大腿。
- 腿部穿著**深褐色大腿襪／過膝襪**。
- 襪口為寬深褐色帶。
- 大腿附近另有細深褐色吊帶／束帶結構，用於連接或固定襪口。
- 襪子的主體與裙子的深褐色為相同顏色。

## 6. 隨身物品：書

- 角色通常手持／攜帶一本深綠色硬皮書。
- 書本封面有金色邊框與中央金色徽飾／裝飾框。
- 參考圖中書本是打開的，但「當下是否打開、手如何拿書」可由姿勢或 surface 改變，不應視為永遠固定的手部姿勢。
- Shell 的 `Book` 碰觸區域指這本書。
- `Book` 單點的物理語意只是「使用者瞧一眼／看一眼角色手上的書」。
- `Book` 單點不代表實際碰觸書本，也不預設使用者對書有興趣、想閱讀、想拿走或有任何特定意圖。
- 若 Runtime 判定為撫摸、抓取等其他 Book gesture，才表示真的和書本發生接觸。

## 7. 其他角色／陪伴者：貓頭鷹

> 此段已使用獨立的貓頭鷹參考圖校驗。以下描述屬於貓頭鷹的穩定外觀；睜眼／閉眼、受驚等表情仍屬 Shell 的動態 surface 狀態。

### 7.1 整體輪廓與配色

- 角色身邊有一隻體型圓潤、羽毛蓬鬆的貓頭鷹，通常停棲在樹枝上。
- 整體羽色以**米白／乳白色、灰褐色與深棕色**三個層次為主。
- 胸腹與臉盤大面積為米白／乳白色；翅膀、肩部與頭頂則混有灰褐與深棕色羽毛。
- 樹枝是貓頭鷹停棲的環境／道具，不是貓頭鷹身體的一部分。

### 7.2 頭部與臉

- 頭部輪廓具有明顯向左右伸出的**角狀耳羽／羽簇**，形成略帶角形的上緣。
- 頭頂主要為深灰褐至深棕色，分布多枚米白色、短長橢圓或水滴狀的小斑點。
- 臉盤本體為米白／乳白色。
- 臉盤外緣，尤其眼睛兩側到下巴周圍，有一圈較深的灰褐／深棕色細羽紋，形成清楚的深色邊界。
- 眼睛為明亮的**琥珀金色至橙金色**，中央瞳孔很深。
- 喙短而尖，為深棕至近黑色，向下收尖。
- 眼睛睜閉與受驚表情不是固定外觀；以即時 Owl surface 為準。

### 7.3 身體與翅膀

- 胸部與腹部大面積為米白／乳白色，下腹帶非常淡的灰米色暈染或斑駁感。
- 上胸與腹部可見數個深灰褐色的簡化弧形／月牙狀羽紋。
- 翅膀具有明顯的**分層覆羽結構**：
  - 上層與中層羽毛交錯米白、灰褐與深棕色。
  - 外側與下方較長的飛羽以深棕色為主。
  - 不要把整片翅膀描述成單一深棕色。
- 頸部下緣與肩部也有一圈深色羽毛，使米白色臉盤與身體之間形成層次。

### 7.4 腳與停棲

- 腳與爪為灰褐色，爪尖較深。
- 常以雙腳抓住樹枝停棲。
- 「停在樹枝上」是常見展示姿態，但不代表所有情境中樹枝都必須被當成貓頭鷹身體的一部分。

### 7.5 Shell 碰觸區域

- `Owl.Head` = 貓頭鷹的頭部／臉部區域。
- `Owl.Bust` = **貓頭鷹的軀幹／胸腹身體區域**。
- `Owl.Wing` = 貓頭鷹的翅膀區域。
- `Owl.Bust` 的 `Bust` 只是 Shell collision 名稱；不要把它和主角色的 `Bust`（女性角色胸部）混為同一種身體語意。

## 8. LLM 解讀硬性規則

1. **Stable Appearance != Current State**
   
   - 本文件描述「通常長什麼樣」。
   - 目前表情、視線、姿勢、眼鏡配戴狀態必須服從 Runtime / SSP / Shell 的即時資料。

2. **不要從單張參考圖固化姿勢**
   
   - 圖中目前低頭看書、手放在書附近，只代表該張圖的姿勢。
   - 不要因此認定角色永遠低頭、永遠把手放在同一位置，或永遠處於閱讀動作。

3. **不要混淆 base/body pose 與服裝**
   
   - 手托下巴、看向使用者、低頭看書等都是動態姿勢。
   - 長外衣、短裙、襪子、頭髮與固定飾品才屬於穩定外觀。

4. **不要誤判下半身的衣物分層**
   
   - 裙子本身是雙層：不透明深色短裙 + 半透明深褐／黑褐色長紗裙。
   - 灰色大腿襪／過膝襪 + 黑色襪口／吊帶是腿部服裝，不屬於裙子。
   - 深藍黑色帶星點的布料是長外衣內襯。
   - 半透明外層紗裙與深藍黑色星點內襯是兩個不同層次，不能互相合併或替代。

5. **碰觸區域使用精確語意**
   
   - `Hair` = 主角色背後長髮。
   - `Book` = 主角色手中的深綠色書。
   - `Bust` = 主角色胸部碰觸區域，不要模糊改寫成一般上半身。
   - `Owl.Head` = 貓頭鷹頭部。
   - `Owl.Bust` = 貓頭鷹軀幹／胸腹身體，不等於主角色胸部。
   - `Owl.Wing` = 貓頭鷹翅膀。
   - 所有 `Owl.*` 都屬於貓頭鷹，不是主角色。
