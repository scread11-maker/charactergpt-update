SSPGPT v0.7 stable online-update channel

This stable channel tracks the current SSPGPT v0.7.x baseline for the Ghost directory sspgpt_proto_v07.

SSP native network update is intentionally limited to bootstrap/presentation-safe text.
It does not replace Runtime, Bridge, MemoryService, TouchProgress, Plug executables, local model assets, editable config/character sources, profile state, memory databases, credentials or logs.
Core architecture and executable changes remain full-NAR updates.

Current baseline: SSPGPT v0.7.1 GPU1 fix13f — stable sent-input mapping/menu cleanup, Cognition Directive Layer, Raw Replay, Shell-scoped Appearance, Memory Recall Cleanup, Shell Semantic Awareness, and graceful shutdown.

The online-update endpoint remains version-stable at v07/.
